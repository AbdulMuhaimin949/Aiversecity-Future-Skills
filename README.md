## Overview

### Problem

Students often struggle to understand which career paths suit their interests and abilities, especially as artificial intelligence and automation continue to change the job market. Career information is scattered across different sources, which makes it hard to identify emerging opportunities and the skills employers may require. Students need an accessible way to explore career options and make more informed decisions about their future.

### Solution

Aiversecity is a career exploration platform that guides users from self-discovery to career planning. It brings together user profiles, career trends, explainable role matches, skill gaps, learning resources, and career pathways. Forecasts and recommendations use documented formulas and labelled data, so users can see what the results mean and where they come from.

### Key Features

- **Career Profile:** Users enter their skills and education, choose interests, select a synthetic persona, or scan a text-based CV. CV scan results can be reviewed before skills are added.
- **Career Radar:** Shows role and skill demand trends under baseline, moderate, and fast AI-disruption scenarios.
- **Career Matches:** Ranks roles against a user's skills, education, experience, interests, learning feasibility, and demand trends, and shows supporting factors and skill gaps.
- **Learning Pathway:** Shows skill gaps and relevant catalogue resources for a selected role. Gaps without a matching resource are flagged instead of being assigned an invented course.
- **Evidence and Sources:** Provides source references and methodology notes for career data and forecasts.
- **SDG Alignment:** Shows links between occupations or skills and the UN Sustainable Development Goals, including SDG 4.

## Architecture

1. **Build the data:** `run_pipeline.py` creates reproducible Bronze, Silver, and Gold CSV datasets using seed 42. The data covers 240 roles across 20 sectors and 255 skills. Synthetic CVs and simulated demand trends are explicitly labelled.
2. **Serve the data:** At startup, the Express API reads the pipeline CSVs into memory and exposes endpoints for the web app.
3. **Collect a profile:** The React app lets users add skills, education, experience, and interests. Profile data stays in the user's browser, and CV scan results are shown for review before they are added.
4. **Calculate career insights:** The API applies a documented weighted formula to rank role matches, builds skill-gap and pathway results from available resources, and returns career and skill forecasts. The forecasting model is Ridge autoregression. Moderate and fast scenarios include documented AI exposure and augmentation adjustments.
5. **Show results:** The app presents the profile, radar, role matches, role details, pathways, sources, and SDG links.

**AI disclosure:** The system does not require an LLM. CV scanning uses a rule-based scanner by default. If a user configures their own OpenAI API key, only the CV scan can use an OpenAI model. Forecasts and role matching never use an LLM.

**Data limitations:** Demand histories and scenario forecasts are simulated estimates, not guarantees or predictions for an individual. Synthetic CV evaluation scores are measured on CVs generated from the same skill-synonym list, so they should not be read as expected accuracy on real CVs. Course coverage is limited, and some skill gaps have no matching resource.

## How to Run

### Run on Replit

1. Open the Aiversecity Replit project.
2. Install dependencies if prompted (`pnpm install`).
3. Start the **API Server** and **web** workflows.
4. Open the web preview, or use the live demo link above.

No database or environment variable is needed for the default experience. `OPENAI_API_KEY` is optional and only enables the OpenAI CV scan.

### Run Locally

Prerequisites: Node.js 24, pnpm, and Python 3.13.

1. Clone the repository:

   ```bash
   git clone https://github.com/AbdulMuhaimin949/Aiversecity-Future-Skills.git
   cd Aiversecity-Future-Skills
   ```

2. Install dependencies and generate the pipeline data:

   ```bash
   pnpm install
   pip install -r requirements.txt
   python run_pipeline.py
   ```

3. Start the API and web app in separate terminals:

   ```bash
   pnpm --filter @workspace/api-server run dev
   ```

   ```bash
   pnpm --filter @workspace/future-skills run dev
   ```

4. Optional checks:

   ```bash
   pnpm run typecheck
   pytest tests
   ```

5. Optional: set `OPENAI_API_KEY` locally to let the CV scan use OpenAI. Never commit API keys or other credentials.

## How We Use Replit

- **Development:** The project is a pnpm workspace with separate Replit workflows for the web app, the API server, and the component preview sandbox. We use Replit to build, run, and preview these services.
- **Hosting:** The app is deployed on Replit and available at https://CtrlCV-AI-Skill.replit.app/.
- **Secrets:** The default app needs none. If OpenAI CV scanning is enabled, the key belongs in Replit Secrets, not in source code.

**Proof of use:** see [`replit-utilization.jpg`](./replit-utilization.jpg).

## How We Use RunPod

RunPod is not used. The repository contains no RunPod endpoint, handler, or integration. The CV scanner runs in the API using local rule-based logic, and forecasting and matching run in the pipeline and API.

## Challenges & Learnings

### Challenges

- Making labour-market and AI-disruption estimates understandable without presenting them as certainty.
- Keeping career recommendations explainable and tied to the user's stated profile.
- Offering useful learning steps while the verified learning-resource catalogue is still small.

### Learnings

- Career recommendations should show their supporting factors and limits, not just a score.
- Clear user journeys help students act on complex career and skills information.
- Synthetic data and simulated forecasts must be labelled and never presented as observed outcomes.
- End-to-end checks are needed to confirm that the web app, API, and generated pipeline data work together.

## Future Improvements

- Improve onboarding so first-time users can complete profiles and understand results more easily.
- Expand verified career data sources and learning-resource coverage.
- Improve the transparency and validation of recommendations and forecasts.
- Personalise learning pathways based on a user's interests, existing skills, and career goals.
