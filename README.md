## Overview

### Problem

Students often struggle to understand which career paths suit their interests and abilities, especially as artificial intelligence and automation continue to change the job market. Career information is scattered across different sources, making it difficult for students to identify emerging opportunities and the skills employers may require. Students need an accessible way to explore career options and make more informed decisions about their future.

### Solution

Aiversecity is a career exploration platform that guides users from self-discovery to career planning. It brings together user profiles, career trends, explainable role matches, skill gaps, learning resources, and career pathways. Its forecasts and recommendations use documented formulas and labelled data so users can understand what the results mean and where they come from.

### Key Features

- **Career Profile:** Users can enter their skills and education, choose interests, select a synthetic persona, or scan a text-based CV. CV scan results can be reviewed before skills are added.
- **Career Radar:** Shows role and skill demand trends under baseline, moderate, and fast AI-disruption scenarios.
- **Career Matches:** Ranks potential roles against a user's skills, education, experience, interests, learning feasibility, and demand trends; shows supporting factors and skill gaps.
- **Learning Pathway:** Shows skill gaps and relevant catalogue resources for a selected role. Gaps without a matching resource are identified rather than assigned an invented course.
- **Evidence and Sources:** Provides source references and methodology notes for career data and forecasts.
- **SDG Alignment:** Shows links between occupations or skills and the UN Sustainable Development Goals, including SDG 4.

## Architecture

1. **Build the data:** `pipeline/run_pipeline.py` creates reproducible Bronze, Silver, and Gold CSV datasets using seed 42. The data covers 240 roles across 20 sectors and 255 skills. Synthetic CVs and simulated demand trends are explicitly labelled.
2. **Serve the data:** At startup, the Express API reads the pipeline CSVs into memory and provides endpoints for the web app. The current app does not require a database.
3. **Collect a profile:** The React app lets users add skills, education, experience, and interests. Profile data is kept in the user's browser; CV scan results are shown for review before they are added.
4. **Calculate career insights:** The API applies a documented weighted formula to rank role matches, builds skill-gap/pathway results from available resources, and returns career and skill forecasts. The forecasting model is Ridge autoregression. Moderate and fast scenarios include documented AI exposure/augmentation adjustments.
5. **Show results:** The app presents the profile, radar, role matches, role details, pathways, sources, and SDG links.

**AI disclosure:** The system does not require an LLM. CV scanning uses a rule-based scanner by default. If the team configures its own OpenAI API key, only the CV scan can use an OpenAI model; forecasts and role matching do not use an LLM.

**Data limitations:** Demand histories and scenario forecasts are simulated estimates, not guarantees or predictions for an individual. Synthetic CV evaluation scores are measured on synthetic CVs generated from the same skill-synonym list, so they should not be treated as expected accuracy on real CVs. Course coverage is limited, and some skill gaps have no matching resource.

## How to Run

### Run on Replit

1. Open the Aiversecity Replit project.
2. Install dependencies if prompted (`pnpm install`).
3. Start the configured **API Server** and **web** workflows. The project has separate workflows for the API and web app.
4. Open the web app preview or the verified published deployment.
5. No database or environment variable is required for the default experience. `OPENAI_API_KEY` is optional and only enables the OpenAI CV scan.

### Run Locally

Prerequisites: Node.js 24, pnpm, and Python 3.13.

1. Clone the GitHub repository after its URL has been supplied:

   ```bash
   git clone <GITHUB_REPOSITORY_URL>
   cd <PROJECT_DIRECTORY>
   ```

2. Install JavaScript dependencies and generate the pipeline data if needed:

   ```bash
   pnpm install
   python pipeline/run_pipeline.py
   ```

3. Start the API and web app in separate terminals:

   ```bash
   pnpm --filter @workspace/api-server run dev
   ```

   ```bash
   pnpm --filter @workspace/future-skills run dev
   ```

4. Optional checks:

   ```bash
   pnpm run typecheck
   pytest pipeline/tests
   ```

5. Optional: set `OPENAI_API_KEY` locally if you want the CV scan to use OpenAI. Do not commit API keys or other credentials.

## Challenges & Learnings

### Challenges

- Making labour-market and AI-disruption estimates understandable without presenting them as certainty.
- Keeping career recommendations explainable and connected to the user's stated profile.
- Providing useful learning steps while the verified learning-resource catalogue is still limited.

### Learnings

- Career recommendations should show their supporting factors and limits, not just a score.
- Clear user journeys help students act on complex career and skills information.
- Synthetic data and simulated forecasts must be clearly identified and not presented as observed outcomes.
- End-to-end checks are needed to verify that the web app, API, and generated pipeline data work together.

## Future Improvements

- Improve onboarding so first-time users can complete profiles and understand results more easily.
- Expand verified career data sources and learning-resource coverage.
- Improve the transparency and validation of recommendations and forecasts.
- Personalise learning pathways based on a user's interests, existing skills, and career goals.
